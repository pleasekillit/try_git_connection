```jsonc
{

  "dns":        { "doh_servers": ["https://223.5.5.5/dns-query"],
                  "tcp_servers": ["8.8.8.8:53"],
                  "resolve_timeout": 4.0,
                  "dns_cache_ttl": 300.0 },
  "speed_test": { "connect_timeout": 2.0, "max_ip_count": 3, "cache_ttl": 300.0 },
  "upstream":   { "connect_timeout": 10.0 },
  "domains":    { }
}
```

### 1.2 域名规则（`data/appsettings/appsettings.*.json`）

```jsonc
{
  "domains": {
    "github.com":     { "tls_sni": false },              // 发送空 SNI
    "*.github.com":   { "tls_ignore_name_mismatch": true },
    "example.com":    { "tls_sni_pattern": "@ipaddress" },
    "blocked.com":    { "response": { "status_code": 404, "content_value": "blocked" } },
    "mirror.com":     { "destination": "https://real.example.com" }
  }
}
```

字段：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `tls_sni` | bool | `true` | 是否发送 SNI；`false` 即空 SNI |
| `tls_sni_pattern` | str/null | `null` | SNI 表达式，支持 `@domain`/`@ipaddress`/`@random` |
| `tls_ignore_name_mismatch` | bool | `false` | 忽略上游证书域名不匹配 |
| `ip_address` | str/null | `null` | 强制使用的上游 IP |
| `timeout` | float/null | `null` | 单次转发超时（秒） |
| `destination` | str/null | `null` | 目标地址改写 |
| `response` | object/null | `null` | 命中后直接返回，不再转发 |

## 2. 模块详细设计

### 2.1 `config/domain_pattern.py` — `DomainPattern`

```python
class DomainPattern:
    def __init__(self, pattern: str) -> None
    def is_match(self, domain: str) -> bool
    def __lt__(self, other) -> bool      # 排序：段数升序，再自右向左比较
    def __eq__(self, other) -> bool      # 忽略大小写
```

- 转换规则：`escape(pattern).replace(r"\*", r"[^\.]*")`，整串锚定，忽略大小写。
  - 例：`*.github.com` → `^[^\.]*\.github\.com$`，故 `a.github.com` ✅，`a.b.github.com` ❌。
- 排序键：`(segments_count, tuple(reversed(segments_with_star_as_\uffff)))`。
  实现"更具体优先"：`a.github.com`（3 段，右侧逐段比较 `a` > `*` 的反面）排在 `*.github.com` 之前。

### 2.2 `config/models.py`

```python
@dataclass(frozen=True)
class ResponseConfig: status_code:int=200; content_type:str="text/plain;charset=utf-8"; content_value:str|None=None

class SniPattern:
    NONE=""; DOMAIN="@domain"; IPADDRESS="@ipaddress"; RANDOM="@random"
    def __init__(self, value:str="") -> None
    def with_domain(self, domain:str)->"SniPattern"
    def with_ip(self, ip:str)->"SniPattern"
    def with_random(self)->"SniPattern"
    @property
    def enabled(self)->bool              # value != ""

@dataclass(frozen=True)
class DomainConfig:
    tls_sni:bool=True; tls_sni_pattern:str|None=None; tls_ignore_name_mismatch:bool=False
    timeout:float|None=None; ip_address:str|None=None
    destination:str|None=None; response:ResponseConfig|None=None
    def sni_pattern(self)->SniPattern    # tls_sni=False→NONE；无 pattern→DOMAIN；否则自定义

@dataclass
class AppConfig:
    proxy:ProxyConfig; dns:DnsConfig; speed_test:SpeedTestConfig; upstream:UpstreamConfig
    domains:list[tuple[DomainPattern,DomainConfig]]   # 已排序
    def match(self, domain:str)->DomainConfig|None
```

### 2.4 `resolver/dns_client.py` — `DnsClient`

```python
class DnsClient:
    def __init__(self, dns:DnsConfig) -> None
    def resolve(self, host:str)->list[str]      # 返回去重、去回环的 IP 列表
```

- 依次尝试：所有 `doh_servers`（`dns.query.https`）→ 所有 `tcp_servers`（`dns.query.tcp`）。
- 单服查询：对 A、AAAA 各发一次 QUERY，取应答中的地址。
- 结果按 TTL 缓存 `host -> (expire_ts, ips)`。
- 异常吞掉并继续下一个服务器；全部失败返回 `[]`。

### 2.5 `resolver/ip_service.py` — `IpAddressService`

```python
class IpAddressService:
    def __init__(self, dns:DnsClient, speed:SpeedTestConfig) -> None
    def get_addresses(self, host:str, port:int)->list[str]   # 按时延升序
```

- `dns.resolve(host)` 得候选 IP（含 `ip_address` 强制项，若配置）。
- 用 `ThreadPoolExecutor` 并发 `_test(ip,port)`：`socket.create_connection` + `perf_counter` 计时。
- 失败记为 `inf` 并过滤；结果加入 `(ip,port)->elapsed` 缓存。
- 只返回前 `max_ip_count` 个。

### 2.7 `certs/ca.py` — `CertAuthority`

```python
class CertAuthority:
    def __init__(self, ca_dir:str|Path) -> None
    def ensure(self)->None                       # 无则生成 CA(cert+key)
    def install_ca(self)->bool                   # 调 certs.installer
    @property ca_cert_path; ca_key_path
    def server_context(self, domain:str)->ssl.SSLContext   # 域名证书 + 服务端 SSLContext
```

- CA：RSA2048，`CN=pyFastGithub`，有效期 10 年，`BasicConstraints(ca=True)`、`KeyUsage`、`SAN`。
- 域名证书：由 CA 签发，`CN=<domain>`，`SAN` 含 domain，有效期 1 年，写盘 `cacert/domains/<safe>.crt|.key`。
- `server_context` 用 `ssl.SSLContext(PROTOCOL_TLS_SERVER).load_cert_chain(crt, key)`。

### 2.9 `proxy/http_message.py`

```python
CRLF=b"\r\n"
def read_head(rfile)->bytes                       # 读到空行（不含）
```

### 2.10 `proxy/upstream.py` — `Upstream`

```python
def build_client_ssl_context(cfg:DomainConfig)->ssl.SSLContext
    # check_hostname=False；ignore_name_mismatch→CERT_NONE，否则 CERT_REQUIRED

class Upstream:
    def __init__(self, resolver:DomainResolver, upstream:UpstreamConfig) -> None
    def connect(self, host, port, use_tls:bool, cfg:DomainConfig)->socket.socket
        # 选最佳 IP；use_tls 时按 sni_pattern 包装 SSL（enabled=False→不发 SNI）
    def exchange(self, sock, request_bytes:bytes)->tuple[bytes,bytes,dict]
```

- `connect`：`ip = cfg.ip_address or resolver.resolve(host)[0]`；逐个候选尝试；`connect_timeout` 生效。
- SNI：`cfg.sni_pattern().with_domain(host).with_ip(ip).with_random()`；`enabled=False` 时 `server_hostname=None`。

### 2.11 `proxy/server.py`

```python
class ProxyServer:
    def __init__(self, app:"Application") -> None
    def start(self)->None      # 后台线程启动 ThreadingTCPServer
    def stop(self)->None

class ProxyHandler(socketserver.BaseRequestHandler):
    def handle(self)->None
```

`handle` 逻辑：
1. `rfile = sock.makefile('rb')`；`head = read_head(rfile)`。
2. 解析首行：`CONNECT host:port` → `_handle_connect`；绝对 URL → `_handle_http`；否则 400。
3. 任意异常：记录日志，关闭连接，不影响其它连接。

`_handle_connect(host, port)`：
- `cfg = config.match(host)`。
- 命中且 `cfg.response` → 回 200 后立刻按 response 配置返回并关闭。
- 命中 → MITM：
  1. 回 `HTTP/1.1 200 Connection Established\r\n\r\n`。
  2. `tls = ca.server_context(host).wrap_socket(sock, server_side=True)`。
  3. 循环：读取请求 → 构造上游请求（`Connection: close`）→ `Upstream.connect` + `exchange` → 回写；按成帧决定是否继续。
- 未命中 → 纯隧道 `_tunnel(host,port)`：连接后双向线程拷贝。

`_handle_http(method, url, head, rfile)`：
- 解析绝对 URL 得 host/port/path；命中规则则走 MITM 的上游逻辑，否则直连。

`Application`（在 `cli` 中组装，或 `proxy/app.py`）：
- 持有 `config`、`domain_resolver`、`upstream`、`ca`、`flow`。
- 提供 `handle(sock, addr)` 供 Handler 调用；供 server 引用。

## 3. 关键算法

### 3.1 域名优先级匹配
按第 2.1 节排序键升序遍历，返回**首个** `is_match` 为真的规则。

### 3.2 IP 测速
```
candidates = dns.resolve(host)
elapsed    = {ip: tcp_connect_time(ip, port) for ip in candidates}   # 并发
result     = [ip for ip in sorted(elapsed, key=elapsed) if elapsed[ip] < inf][:max_ip_count]
```

### 3.3 SNI 决策
```
cfg.tls_sni == False                 -> ""            # 不发 SNI
cfg.tls_sni_pattern is None/""       -> "@domain"     # 发真实域名
else                                  -> 按变量替换
```

### 3.4 上游证书校验
```
ctx = create_default_context()
ctx.check_hostname = False
ctx.verify_mode = CERT_NONE if cfg.tls_ignore_name_mismatch else CERT_REQUIRED
```

## 4. 错误处理

| 场景 | 行为 |
|---|---|
| 配置缺失/损坏 | 启动失败并打印明确错误 |
| DNS 全部失败 | 上游连接失败，返回 502，记录日志 |
| 上游连接失败 | 尝试下一个 IP；全失败返回 502 |
| 客户端走非 HTTP 协议 | 关闭连接，记录日志 |
| CA 未安装 | 提示执行 `install-ca`，服务仍可启动 |
